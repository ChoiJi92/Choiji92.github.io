# 이음 · Ieum

이음이 만드는 앱 소개 사이트 — https://choiji92.github.io

- 첫 화면: 만든 앱 다섯 개(도쿠도쿠 마을, 뭐해?, 할렐루양, 그때폰카, 토스 미니앱 이음사주)와 자기소개. 스레드 프로필 링크로 쓴다
- 앱마다 스토어 링크, 지원, 개인정보처리방침. 앱 아이콘과 화면 그림은 `img/apps/`
- `app-ads.txt`: AdMob 앱 인증용 (스토어에 적는 개발자 웹사이트가 이 주소여야 한다)
- `join/`: 할렐루양 공개 소그룹 링크 페이지
- `i/`: 할렐루양 친구 초대 링크 페이지 (`/i/?c=코드&n=닉네임`) — 코드 복사, 앱에서 열기(`halleluyang://redeem?code=`), App Store

예전 포트폴리오는 git 기록(2026-09-27 이전 커밋)과 `gh-pages` 브랜치에 남아 있다.
